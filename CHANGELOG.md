# Changelog

All notable changes to `flap-task-flow` are documented here.

## [1.0.0] - 2026-11-03
### Added
- Core agile Kanban task management board with React 18 and Vite.
- Dynamic task creation, status toggling, and deletion handlers.
- Route-based deep task inspection with `react-router-dom`.
- Utility-first responsive design tokens with Tailwind CSS and Lucide icons.
- GitHub Actions CI workflow for automated linting and build validation.
